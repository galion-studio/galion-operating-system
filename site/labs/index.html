The kit

Ready to drop in. The organisation is not created yet.

A GitHub organisation cannot be created through the API this project can call. Maciej Grajczyk creates galion-labs in the GitHub UI, when he chooses to. Until that click, the kit in this repository is Galion Labs.

The kit holds a readme, contributing notes, governance, a security policy, issue forms, discussion forms, and a profile readme for the future organisation. The code of conduct is the Contributor Covenant, version 2.1, attributed in the file.

For the owner

What still has to be done by hand.

Create the GitHub organisation. Copy the kit into a public .github repository, with the profile readme at profile/README.md. Switch Discussions on if you want the discussion templates. Choosing a host for these pages, and approving any deploy, is a separate decision. This repository does not deploy them, and it does not change DNS.

Pricing

Three ways in. One of them is free forever.

Galion OS is free forever and open source. Plus is Galion One, at $20 / €20 per month. Ultra is Galion Research, at $220 / €220 per month. Galion Voice is the voice model inside Galion One. It is not a separate product, and it has no price of its own. Billing is not live. paid_tiers stays false. Nothing on this page takes a card.
