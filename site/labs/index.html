The kit

Ready to drop in. The organisation is not created yet.

A GitHub organisation cannot be created through the API this project can call. Maciej Grajczyk creates galion-labs in the GitHub UI, when he chooses to. Until that click, the kit in this repository is Galion Labs.

The kit holds a readme, contributing notes, governance, a security policy, issue forms, discussion forms, and a profile readme for the future organisation. The code of conduct is the Contributor Covenant, version 2.1, attributed in the file.

For the owner

What still has to be done by hand.

Create the GitHub organisation. Copy the kit into a public .github repository, with the profile readme at profile/README.md. Switch Discussions on if you want the discussion templates. Choose a host for these pages, and approve any deploy. This repository does none of those.

Planned pricing

Local is free forever. Hosting is a plan.

Galion OS, Obsidian Open Mind, Galion Research, and Galion One are free and open source. On hardware you control, Galion Voice is a free program too. Plus and Ultra are optional hosted computers for a person without that hardware. The prices are the owner's planned prices. Billing is not implemented. paid_tiers stays false. Nothing on this page takes a card.
