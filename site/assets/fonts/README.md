# Fonts on the landing pages

*Maciej Grajczyk · 2026-11-09 (Europe/Zagreb, CET, UTC+1).*

The WOFF2 files in this folder are Latin subsets of three SIL Open Font License 1.1 families, self-hosted so the pages do not call a third-party font host.

| File | Family | Weight | Upstream |
|---|---|---|---|
| `jost-500.woff2` | Jost | 500 | Copyright 2020 The Jost Project Authors. See `OFL-Jost.txt`. |
| `ibm-plex-sans-400.woff2` | IBM Plex Sans | 400 | Copyright © 2017 IBM Corp. Reserved Font Name "Plex". See `OFL-IBM-Plex-Sans.txt`. |
| `ibm-plex-sans-500.woff2` | IBM Plex Sans | 500 | Same licence. |
| `ibm-plex-sans-600.woff2` | IBM Plex Sans | 600 | Same licence. |
| `ibm-plex-mono-400.woff2` | IBM Plex Mono | 400 | Copyright © 2017 IBM Corp. Reserved Font Name "Plex". See `OFL-IBM-Plex-Mono.txt`. |
| `ibm-plex-mono-500.woff2` | IBM Plex Mono | 500 | Same licence. |

The subsets cover Basic Latin, Latin-1, the euro sign, and a few dashes and quotation marks. They are not the full fonts, and they are not sold on their own. The wordmark outlines in `docs/brand/marks/` are drawn from Jost 500 for the name Galion.
