Galion Operating System

Free. Open. On your CPU.

Galion OS is the operating system at the root of galion.app. It is Linux-based and CPU-first. It is free forever, and the licence is MIT. The image is in development.

The seamless connection with the human being, on the voice only.

Operating System Pricing

The base

Linux, then a calm machine.

The system is small on purpose. Private by default means the machine in front of you is the one that holds the work. A GPU is not the premise. The CPU owns the loop.

Obsidian Open Mind is the desktop layer inside Galion OS. Memory, tools, and agents sit there. It is a Galion project, and it is a different project from the Obsidian note-taking app.

Galion One is the companion on that desktop. Galion Research looks things up and says what the looking found. Galion Voice is the voice model inside Galion One. It is not a separate product.

Status

What is true today.

This repository holds documents: the direction, the two image profiles, and the one-dot surface spec. It does not hold a bootable image. galion-init prints one desktop boot: the console, then research, then the handoff at /one. It does not replace the host init, and it does not play a tone.

The voice model is an engineering program inside Galion One. A learned student model is not shipped. The learned emotion detector is in development. Until a listener is ratified, these pages do not say that a call was understood.

Open Mind is a Rust workspace for a CPU box. Read that repository for what is built and what is still a scaffold.

Billing is not live. paid_tiers stays false.
