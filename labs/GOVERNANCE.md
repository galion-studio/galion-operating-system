# Governance

*Maciej Grajczyk · 2026-11-09 (Europe/Zagreb, CET, UTC+1).*

Galion Labs is the open community and research arm of Galion. It has a steward, and it has a public record. This note says which decisions sit where.

## Steward

The steward is **Maciej Grajczyk**, Galion Studio, owner of the GitHub organisation `galion-studio`.

The steward:

- Creates the `galion-labs` GitHub organisation, in the GitHub UI, when he chooses to. This kit does not create it.
- Decides the names in the brand guide, the licence, and the locks a product repository already names (`paid_tiers`, the one-dot surface, consent defaults).
- Approves any deploy of the landing pages, and any host they would use.
- Merges changes to the brand guide, this kit, and the product locks.
- Names further maintainers in an edit to this file when he wants them. Until that edit, the steward is the only maintainer.

## What the community does

Anyone may:

- Open an issue or a discussion.
- Propose a research note, a correction, or a document change in a pull request.
- Use the MIT-licensed code and documents, within that licence.

A proposal is a suggestion. It becomes part of the project when the steward merges it. Labs does not run a vote that overrides a product lock.

## How a proposal moves

1. An issue or a discussion states the idea, what is known, and what is still open.
2. A pull request carries the change.
3. The steward merges it, asks for a revision, or leaves it open with a reason.

Silence is not acceptance. A merged commit is the record.

## Conduct

[CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) is Contributor Covenant 2.1. The steward enforces it. Reports go to him in private, as that file says.

## Money

Local use is free forever. Plus at $20 / €20 per month and Ultra at $220 / €220 per month are planned prices for optional hosted computers. Billing is not implemented. A governance change does not switch `paid_tiers` to true. That switch is an owner edit of the voice licence lock, with counsel, recorded by the owner.

Galion Labs itself has no fee.
