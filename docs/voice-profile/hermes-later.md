# Hermes GUI — the later profile

*Maciej Grajczyk · 2026-11-02 (Europe/Zagreb, CET, UTC+1).*

The Hermes GUI is the later image profile of Galion Operating System. It is the one-window computer described in the root README, built on the same base as [Galion OS Voice](voice-first.md), and it ships after that voice-first image.

## What you see

One window. One gradient. One prompt field. You type or you speak, and the work happens in front of you.

- The window sits on deep obsidian black, with the same slow amber-to-violet wash as the Voice profile (`#0A0A0C`, `#F5A524`, `#7C3AED`).
- There is no menu to learn and no folder tree to manage.
- Agents show up as soft glowing presences while they work. There is no spinner.
- Sounds for starting, finishing, notices, and questions stay quiet at night and when muted.
- Anything important asks first.

The one-dot rule belongs to Galion OS Voice. This later profile is the window: the prompt field is on screen, and Hermes is the centre of that screen.

## Where Hermes sits

On this profile Hermes is the centre of the screen for knowledge and tools. The same role exists on the Voice profile, where Hermes stays off the device on the side band and is never drawn. Here the role is visible: the window is how you meet it.

The 80 ms audio path still belongs to the voice loop whenever voice is in the turn. Hermes remains the slow mind. A late answer is said out loud as a late answer. The voice loop does not wait inside the frame, and it does not invent a result.

Which Hermes build is live — the Rust gateway or the published Python line — stays an owner pick. This profile note does not choose the binary and does not place one in the tree.

## What it shares with the first profile

Both profiles boot through `galion-init` and use the Obsidian Open Mind contract. Both are free to download under the Galion OS MIT licence. Both keep Hermes as the centre for knowledge and tools. The Voice profile simply ships first, with no display server and with Hermes off the image.

Galion Voice on plain Linux uses neither profile. Someone can run the program without installing Galion OS at all.
