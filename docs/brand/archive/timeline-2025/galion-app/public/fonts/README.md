# Fonts

Place any custom fonts here for the Jarvis demo.

The demo will work without custom fonts - it will fall back to system monospace fonts.

## Recommended Fonts

For the most authentic Iron Man look, consider using:

1. **Roboto Mono** - Clean, technical feel
2. **Orbitron** - Futuristic sci-fi aesthetic  
3. **Share Tech Mono** - Technical display font
4. **Exo 2** - Modern geometric font

You can download these from Google Fonts and place the `.woff` or `.woff2` files here.
